## 一、产品理念

**用度** 是一款帮助用户量化生活成本的工具型小程序。

用户记录每一笔消费（商品、服务、会员等），系统自动将成本分摊到每一天或每一次使用。用户通过持续观察自己每一天的「用度」——看见有形成本与无形成本，掌握自己的生活节奏，识别消费陷阱，建立更理性的消费观念。

**核心理念**：让每一分钱花得清晰，让每一个决定有数据支撑。

### 3.2 物品状态（status）

| 状态 | 说明 | 成本计算 |
|------|------|----------|
| 使用中 | 正常使用中 | 正常参与统计 |
| 已废弃 | 不再使用（如坏了/丢了） | 不参与统计，显示废弃标记 |
| 已卖出 | 已转让他人 | 不参与统计，记录卖出价格和卖出时间（卖出相关数据暂不参与计算，后续再扩展） |

### 3.3 计算单位（unit）

系统仅支持两种计算单位：

**① 按天（day）**
- 适用：一切有使用寿命的商品（手机/电脑/家电/衣物等）
- 公式：**每日成本 =（价格 + 其他费用）÷ 已使用天数**
- 特性：时间越长，每日成本越低（折旧模型）
- 天数计算：`(当前日期 - 购买日期)` 的天数差，向上取整

**② 按次（count）**
- 适用：有使用次数的消费（健身卡/咖啡券/打印次数等）
- 公式：**每次成本 =（价格 + 其他费用）÷ 已使用次数**
- 特性：使用次数越多，每次成本越低
- 注意：**无预设总次数**，用户每次使用点一下加号，即时计算当前每次成本
- 卡片上的加号按钮：用户点一次 = 使用一次，`usedCount + 1`

- 点击展开搜索，支持按以下字段模糊搜索：
  - 物品名称
  - 备注内容
  - 时间范围（购买日期区间）
- 搜索结果覆盖列表区域

#### 5.1.4 成本汇总区（视觉重点）

```
┌─────────────────────────────────────┐
│  今日成本                            │
│  ¥ 48.6                            │
│                                     │
│  平均每次成本                        │
│  ¥ 32.4 （按次物品 · 共X件）         │
└─────────────────────────────────────┘
```

- **今日成本**：所有「使用中」且「按天」物品的每日成本之和（保留2位小数）
- **平均每次成本**（按次物品汇总）：
  - 公式：所有按次物品总价之和 ÷ 所有按次物品已用次数之和
  - 显示：「¥ XX.X （按次物品 · 共X件）」
  - 例：健身卡5000元用3次=1666.7元/次，咖啡券200元用10次=20元/次
  - 平均每次 = (5000 + 200) ÷ (3 + 10) = 5200 ÷ 13 = 400元/次

## 六、统计计算公式

### 按天物品（使用中）

```
每日成本 = (价格 + 其他费用) ÷ 已使用天数
已使用天数 = ceil(当前日期 - 购买日期)
```

### 按次物品（使用中）

```
每次成本 = (价格 + 其他费用) ÷ 已使用次数
（无预设总次数，已使用次数从1开始累加）
```

### 汇总指标

```
今日成本 = Σ(所有"使用中"且unit=day的物品每日成本)

平均每次成本 = Σ(所有"使用中"且unit=count的物品总价) ÷ Σ(所有"使用中"且unit=count的物品已用次数)
```

## 十一、按次物品初始状态说明（补充）

按次物品（unit=count）的已用次数 `usedCount` 初始值为 **0**。

**当 usedCount = 0 时**：
- 卡片显示「已用0次 · 每次--」
- 原因：被除数不能为0，无法计算出每次成本
- 等用户点一次加号后，usedCount 变为1，即可计算出每次成本

## 十二、最终确认事项

所有待确认事项已解决：

| 问题 | 结论 |
|------|------|
| 按周期 | 删除，只保留按天和按次 |
| 按次总次数 | 无预设总次数，成本=总价÷已用次数 |
| 平均每次成本公式 | Σ(按次物品总价) ÷ Σ(按次物品已用次数) |
| 初始已用次数 | 0，为0时显示"--" |
| 类别体系 | 预置类别 + 用户自定义类别（可长按删除） |
| 已卖出 | 记录卖出价格和卖出时间（暂不参与计算） |
